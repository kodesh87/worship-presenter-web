- (decision) AD-1 (Registry Storage): The live Artifact Registry will be stored in SQLite to unify storage targets and handle concurrency. data/default-registry.json serves only as an initial seed. - (decision) AD-2 (Data Flow): buildSlidePlan outputs a fully hydrated AST (Fat Payload) with exact rendering coordinates, fonts, and content. Binds: The output shape of buildSlidePlan. Prevents: Web and PPTX renderers from performing independent DB lookups or managing layout logic.
- (decision) AD-3 (Canvas State Boundary): The Canvas Editor uses an Uncontrolled Wrapper pattern. Fabric.js owns the canvas state exclusively; React only reads state via canvas.toJSON() on save. Binds: React-Fabric integration boundary. Prevents: Two-way binding lag and unnecessary React re-renders during drag/drop.

- (decision) AD-6 (Service-Bound Registry Snapshot): supersedes ONLY the global-across-services clause of AD-4. Creating a service clones the ordered live registry into a service-bound snapshot on the durable DB_PATH; a live registry edit does not reach an existing service; Sync Artifact re-clones destructively. Binds: service create, Sync Artifact, buildSlidePlan input, the ordered registry. Prevents: a registry edit silently changing a service an operator already reviewed. AD-4 admin-only authorization and read-through-server-side-modules clauses SURVIVE.
- (decision) AD-6 sub-decision, owner call: Sync Artifact is always permitted, including on a service already presented. Accepted cost stated in the spine rather than left implicit: the parent conventions line services are immutable once presented is punctured for structure, and no snapshot can be relied on to reconstruct the deck a congregation actually saw on a given Sabbath. Owner chose this over restricting Sync to the review window.
- (decision) AD-7 (Seed Is Bootstrap, Not A Correction Channel): supersedes the startup-inserts-missing-template-IDs clause of AD-1. Seeding is gated by a settings marker and runs once; after it, boot never inserts, re-seeds, relabels or reorders. Resolves the AD-1 vs CAP-2 collision: a deleted entry left no evidence, so the seeder read it as never-existed and resurrected it every boot. Binds: getDb startup path, registry store, delete verb, ordering column. Prevents: an administrator deletion, rename or reorder being undone by an unrelated restart.
- (decision) AD-8 (Vocabulary And Value Changes Travel As Explicit Migrations): a shipped change that must reach persisted rows travels as one explicit marker-gated migration on the startup path, never as boot-time re-seed. Precedent already in code: artifact_seed_hash_backfilled. Owner decision: pre-first-deploy the seven-to-three base_type collapse is a total replacement with no backward compatibility and no incremental migration - developer databases are rebuilt. Expiry recorded: that waiver ends at first deploy.
