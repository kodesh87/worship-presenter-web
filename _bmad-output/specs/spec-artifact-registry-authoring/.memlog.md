- (direction) Full canvas authoring vision is in scope: add/delete/reorder slides; change layout; insert/reposition/resize background, images, text, and text areas with font color/size/style including bold italic underline.
- (direction) Placeholders are a central predefined catalog; operators insert any predefined placeholder into any slide template and style it; adding a new placeholder kind still requires code.
